# MTF Divergence Matrix

A multi-timeframe divergence indicator for TradingView designed to detect and visualize RSI divergence across up to three configurable timeframes.

The indicator was built to complement multi-timeframe chart pattern analysis by adding divergence confirmation directly on the price chart.

Instead of relying only on signals from the current chart timeframe, MTF Divergence Matrix allows traders to monitor lower, current, and higher timeframe divergence simultaneously.

For example:

- M5
- M30
- H4

while remaining on an M5 chart.

### Multi-Timeframe Divergence Detection
